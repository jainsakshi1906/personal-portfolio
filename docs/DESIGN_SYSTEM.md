# Personal Portfolio Website – Design System
Version: 1.0

## Design Philosophy
Blend:
- 60% Apple-inspired minimalism
- 30% Modern SaaS
- 10% Corporate professionalism

Keywords: Clean, Airy, Elegant, Structured, Premium.

## Color Tokens
| Token | Value | Usage |
|---|---|---|
| Primary | #2563EB | CTAs, links |
| Accent | #7C3AED | Highlights |
| Background | #F8FAFC | App background |
| Surface | #FFFFFF | Cards |
| Text Primary | #111827 | Main text |
| Text Secondary | #4B5563 | Supporting text |
| Border | #E5E7EB | Dividers |

## Typography
Headings: Poppins
Body: Inter

Scale:
Display 56
H1 48
H2 36
H3 28
H4 22
Body 16
Small 14

## Spacing
8px system:
4,8,16,24,32,48,64,80,96,128

Section spacing:
Desktop: 96px
Tablet: 80px
Mobile: 64px

## Grid
Desktop: 12 columns
Tablet: 8 columns
Mobile: 4 columns

Container max width: 1280px.

## Radius
8 / 12 / 20 / 28 px.

## Shadows
Level1: subtle cards
Level2: hover
Level3: dialogs

## Buttons
Primary, Secondary, Ghost.
Consistent height, rounded corners, subtle hover.

## Cards
Project cards:
- image
- title
- summary
- chips
- CTA

No excessive decoration.

## Forms
Simple labels, clear validation, accessible focus.

## Icons
Lucide as default. React Icons only when needed.

## Motion
Framer Motion.
200–350ms ease-out.
Fade + slight translate.
Honor reduced-motion.

## Responsive Rules
Equal priority mobile and desktop.
No horizontal scrolling.

## Accessibility
WCAG AA.
Minimum contrast.
Keyboard navigation.
Visible focus.
Semantic HTML.

## Design Guardrails
Avoid:
- Skill progress bars
- Heavy gradients
- Floating particles
- Glassmorphism overuse
- Long paragraphs
- Inconsistent spacing
